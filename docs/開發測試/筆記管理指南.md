# 筆記管理指南

筆記存放在 `personal/notes` 分支，本地透過 `.git/info/exclude` 隱藏，不會影響工作分支。

## 筆記涵蓋的目錄

```
AGENTS.md
docs/contribution-playbook/
docs/developer-guide/
docs/vm0-audit-report/
docs/開發測試/
```

---

## 日常操作

### 1. 寫筆記

直接在本地編輯檔案即可，這些路徑已被 exclude，不會出現在 `git status`。

```bash
# 新增或編輯筆記
vi "docs/開發測試/新筆記.md"
```

### 2. 推送筆記到遠端

```bash
# 暫存工作區變更（如果有的話）
git stash

# 切到筆記分支
git checkout personal/notes

# 複製筆記進來（從 main 的工作目錄帶過來的檔案會自動在這裡）
git add AGENTS.md docs/contribution-playbook/ docs/developer-guide/ docs/vm0-audit-report/ "docs/開發測試/"
git commit -m "docs: update notes"
git push origin personal/notes

# 切回工作分支
git checkout main

# 恢復工作區
git stash pop
```

**簡化版（一行）：**

```bash
git stash && git checkout personal/notes && git add AGENTS.md docs/contribution-playbook/ docs/developer-guide/ docs/vm0-audit-report/ "docs/開發測試/" && git commit -m "docs: update notes" && git push origin personal/notes && git checkout main && git stash pop
```

### 3. 從遠端拉取筆記（新機器 / 同步）

```bash
# 抓取最新的筆記分支
git fetch origin personal/notes

# 用筆記分支的檔案覆蓋本地
git checkout origin/personal/notes -- AGENTS.md docs/contribution-playbook/ docs/developer-guide/ docs/vm0-audit-report/ "docs/開發測試/"

# Unstage（變回 untracked）
git reset HEAD -- AGENTS.md docs/contribution-playbook/ docs/developer-guide/ docs/vm0-audit-report/ "docs/開發測試/"
```

### 4. 新機器首次設定

在拉取筆記之後，還需要加入 exclude 規則：

```bash
cat >> .git/info/exclude << 'EOF'
docs/contribution-playbook/
docs/developer-guide/
docs/vm0-audit-report/
docs/開發測試/
AGENTS.md
EOF
```

---

## 原理說明

| 機制 | 作用 |
|------|------|
| `personal/notes` 分支 | 遠端儲存筆記，與 main 完全分離 |
| `.git/info/exclude` | 本地忽略規則，不會被 commit 進 repo |
| `git checkout <branch> -- <path>` | 從指定分支抽取檔案到工作目錄 |
| `git reset HEAD` | 把 staged 的檔案退回 untracked 狀態 |

## 注意事項

- `.git/info/exclude` 是**本地設定**，每台新機器都要重新加
- 推送前記得先 `git stash` 保存工作進度
- 筆記分支只放筆記，不要在上面做開發

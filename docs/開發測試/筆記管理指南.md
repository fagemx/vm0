# 筆記管理指南

筆記存放在 `personal/notes` 分支，透過 **git worktree** 掛載到獨立目錄，不需切換分支。

## 目錄結構

```
/home/ubuntu/vm0/          ← 工作分支（main, fix/xxx, test/xxx）
/home/ubuntu/vm0-notes/    ← personal/notes 分支（永駐）
```

筆記都在 `/home/ubuntu/vm0-notes/docs/開發測試/` 下：

```
docs/開發測試/
├── 多代理測試流程/
│   ├── briefing.md                 # API route 測試規範
│   ├── briefing-page-level.md      # Page-level metadata 測試規範
│   ├── agent-teams-調查.md         # Agent Teams 實戰筆記
│   ├── 執行紀錄.md
│   ├── 已知陷阱.md
│   ├── 流程設計.md
│   └── README.md
├── 遺漏事件紀錄/
├── 方法論/
└── ...
```

## 日常操作

### 1. 編輯筆記

直接讀寫 `/home/ubuntu/vm0-notes/` 下的檔案，不影響工作分支：

```bash
vi /home/ubuntu/vm0-notes/docs/開發測試/新筆記.md
```

### 2. 推送筆記

```bash
cd /home/ubuntu/vm0-notes
git add -f "docs/開發測試/新筆記.md"
git commit -m "docs: add new note"
git push origin personal/notes
```

> `-f` 是因為 `.gitignore` 擋中文路徑，force add 覆蓋忽略規則。

### 3. 拉取最新筆記

```bash
cd /home/ubuntu/vm0-notes
git pull origin personal/notes
```

## 首次設定（新機器）

```bash
# 1. Clone repo（如果還沒有）
git clone <repo-url> /home/ubuntu/vm0

# 2. 建立 worktree
cd /home/ubuntu/vm0
git fetch origin personal/notes
git worktree add /home/ubuntu/vm0-notes personal/notes

# 3. 加入 exclude 規則（讓工作分支不會看到筆記檔）
cat >> .git/info/exclude << 'EOF'
docs/contribution-playbook/
docs/developer-guide/
docs/vm0-audit-report/
docs/開發測試/
AGENTS.md
EOF
```

---

## 原理說明

| 機制 | 作用 |
|------|------|
| `personal/notes` 分支 | 遠端儲存筆記，與 main 完全分離 |
| `git worktree` | 同一個 repo 掛載兩個 working directory，各自獨立分支 |
| `.git/info/exclude` | 本地忽略規則，讓工作分支不看到筆記檔 |
| `git add -f` | 覆蓋 .gitignore 的忽略規則，強制加入追蹤 |

## 注意事項

- worktree 建立後**不要刪除 `/home/ubuntu/vm0-notes/`**，否則要重建
- 如需移除 worktree：`git -C /home/ubuntu/vm0 worktree remove /home/ubuntu/vm0-notes`
- 筆記分支只放筆記，不要在上面做開發
- `.git/info/exclude` 是本地設定，每台新機器都要重新加

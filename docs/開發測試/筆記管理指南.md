# 筆記管理指南

所有工作目錄透過 **git worktree** 掛載，不需切換分支。

## 目錄結構

```
/home/ubuntu/vm0/          ← 主要開發（長時間任務，feature branch）
/home/ubuntu/vm0-fix/      ← 快速修正（detached，隨時 checkout PR 分支）
/home/ubuntu/vm0-main/     ← 研究 / 讀 code / 開新分支（永駐 main）
/home/ubuntu/vm0-notes/    ← 筆記（永駐 personal/notes）
```

### 使用場景

| 場景 | 用哪個目錄 |
|------|-----------|
| 開發新功能 / 跑測試 / rebase | `vm0` |
| PR review 回來要快速修一行 | `vm0-fix`（`git checkout <pr-branch>`） |
| 研究 issue、讀 main 上的 code | `vm0-main` |
| 寫筆記 | `vm0-notes` |

### 為什麼需要多個 worktree？

`vm0` 跑 rebase / 測試時會長時間佔用，無法同時處理其他 PR 的 review 修正。
`vm0-fix` 用 detached HEAD，不綁定特定分支，用完 checkout 下一個 PR 即可。

## 日常操作

### 1. 編輯筆記

直接讀寫 `/home/ubuntu/vm0-notes/` 下的檔案，不影響工作分支：

```bash
vi /home/ubuntu/vm0-notes/docs/開發測試/新筆記.md
```

### 2. 推送筆記

```bash
cd /home/ubuntu/vm0-notes
git add -f "docs/開發測試/新筆記.md"
git commit -m "docs: add new note"
git push origin personal/notes
```

> `-f` 是因為 `.gitignore` 擋中文路徑，force add 覆蓋忽略規則。

### 3. 拉取最新筆記

```bash
cd /home/ubuntu/vm0-notes
git pull origin personal/notes
```

### 4. 用 vm0-fix 快速修 PR

```bash
cd /home/ubuntu/vm0-fix
git fetch origin
git checkout test/some-pr-branch    # checkout 要修的 PR 分支
# ... 修改、commit、push ...
git checkout --detach               # 用完回到 detached 狀態
```

### 5. 同步 vm0-main 到最新

```bash
cd /home/ubuntu/vm0-main
git pull upstream main
```

## 首次設定（新機器）

```bash
# 1. Clone repo（如果還沒有）
git clone <repo-url> /home/ubuntu/vm0

# 2. 建立所有 worktree
cd /home/ubuntu/vm0
git fetch origin personal/notes
git worktree add /home/ubuntu/vm0-notes personal/notes
git worktree add /home/ubuntu/vm0-main main
git worktree add --detach /home/ubuntu/vm0-fix

# 3. 加入 exclude 規則（讓工作分支不會看到筆記檔）
cat >> .git/info/exclude << 'EOF'
docs/contribution-playbook/
docs/developer-guide/
docs/vm0-audit-report/
docs/開發測試/
AGENTS.md
EOF
```

## 原理說明

| 機制 | 作用 |
|------|------|
| `personal/notes` 分支 | 遠端儲存筆記，與 main 完全分離 |
| `git worktree` | 同一個 repo 掛載多個 working directory，各自獨立分支 |
| `--detach` | 不佔用任何分支名，可自由 checkout 任何 PR 分支 |
| `.git/info/exclude` | 本地忽略規則，讓工作分支不看到筆記檔 |
| `git add -f` | 覆蓋 .gitignore 的忽略規則，強制加入追蹤 |

## 注意事項

- worktree 建立後**不要刪除目錄**，否則要重建
- 如需移除 worktree：`git -C /home/ubuntu/vm0 worktree remove /home/ubuntu/vm0-fix`
- 查看所有 worktree：`git worktree list`
- 筆記分支只放筆記，不要在上面做開發
- `.git/info/exclude` 是本地設定，每台新機器都要重新加
- `vm0-fix` 用完記得 `git checkout --detach`，避免佔住分支名

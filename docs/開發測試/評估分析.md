  缺點 👎

  1. 開發速度較慢

  ┌────────────────────────────────────────────────────────────┐
  │  任務                    │  TypeScript  │  Rust           │
  ├────────────────────────────────────────────────────────────┤

  │  修改資料結構             │  5 分鐘      │  30 分鐘         │

  │  找 Bug                  │  console.log │  編譯器幫你找     │
  └────────────────────────────────────────────────────────────┘

  開發同樣功能，Rust 可能需要 2-3 倍時間
  但維護和 Debug 時間會大幅減少

  2. 生態系統差異

  Node.js 優勢：
  ├── Clerk SDK          → Rust 無官方 SDK，需自己包 REST API
  ├── E2B SDK            → Rust 無官方 SDK
  ├── Vercel 部署        → Rust 需要自己處理
  ├── Next.js 全棧       → Rust 前後端分離
  └── NPM 套件生態       → Cargo 生態較小

  需要自己實作或包裝的：
  • Clerk 認證 (REST API)
  • E2B 沙箱 (REST API)
  • 或直接用 Firecracker (Rust 反而更適合)

  3. 團隊技能要求

  Rust 要求：
  • 理解 ownership/borrowing
  • async/await + Pin + Future
  • 生命週期 ('a, 'static)
  • 泛型 + trait bounds

  找 Rust 工程師難度 > Node.js

  詳細功能分類

  1. 認證管理 (vm0 auth)

  vm0 auth login          # 登入 VM0 平台
  vm0 auth logout         # 登出
  vm0 auth status         # 查看認證狀態
  vm0 auth setup-token    # 取得 API Token

  2. Agent 生命週期管理 (vm0 agent)

  # 建立/部署
  vm0 init                        # 初始化新專案
  vm0 compose                     # 部署 Agent 到雲端

  # 查詢
  vm0 agent list                  # 列出所有 Agent
  vm0 agent status <name>         # 查看 Agent 狀態/版本

  # 複製
  vm0 agent clone <name> ./local  # 下載 Agent 定義到本地

  # 執行
  vm0 run <agent> "prompt"        # 執行 Agent
  vm0 cook "prompt"               # 快速：compose + run 一步完成

  3. 排程管理 (vm0 schedule)

  vm0 schedule setup <agent>      # 建立/編輯排程
  vm0 schedule list               # 列出所有排程
  vm0 schedule status <agent>     # 查看排程狀態
  vm0 schedule enable <agent>     # 啟用排程
  vm0 schedule disable <agent>    # 停用排程
  vm0 schedule delete <agent>     # 刪除排程

  排程功能：
  ├── Cron 表達式支援 (0 9 * * * = 每天 9 點)
  ├── 自動執行 Agent
  ├── 可設定執行參數
  └── 執行歷史追蹤

  4. 儲存管理

  Volume（輸入資料）

  vm0 volume init                 # 初始化 Volume
  vm0 volume push                 # 上傳本地檔案
  vm0 volume pull                 # 下載雲端檔案
  vm0 volume list                 # 列出所有 Volume
  vm0 volume status               # 查看狀態
  vm0 volume clone <name> ./dir   # 複製到本地

  Artifact（輸出結果）

  vm0 artifact init               # 初始化 Artifact
  vm0 artifact push               # 上傳
  vm0 artifact pull               # 下載
  vm0 artifact list               # 列出所有 Artifact
  vm0 artifact status             # 查看狀態
  vm0 artifact clone <name> ./dir # 複製到本地

  Volume vs Artifact：
  ┌──────────────────────────────────────────────────────────┐

## 答案：他們有自動化 Code Review 系統

### 🤖 Claude Code `/pr-review` Skill

vm0 專案內建了一套自動化 code review 流程：

```
/pr-review → 調用 code-quality skill → 生成 17 種 Bad Smell 分析報告
```

`code-quality` skill 定義了 **17 種 Bad Smell 分類**，其中直接相關的有：

| Bad Smell # | 類別 | 抓到的問題 |
|-------------|------|-----------|
| #8 | Test Mock Cleanup | `vi.clearAllMocks()` / mock 狀態洩漏 |
| #12 | Direct DB in Tests | `globalThis.services.db` 直接操作 |
| #16 | AP-4 Internal Mocking | `vi.mock()` 相對路徑 |

### 📊 `vi.unstubAllEnvs()` 的規模

整個 codebase 有 **48+ 個測試檔案**都使用了 `vi.unstubAllEnvs()`。Reviewer 很可能：

1. 已經知道這是一個**全專案待清理的模式**
2. 看到我們新加的測試沿用了這個模式，就順手指出

```
項目自動化工具（Claude Code Skills）
```
